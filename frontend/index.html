⚙️ Repairman Problem Simulation by (21SW037 & 21SW123)

Problem Statement

A factory has M identical machines that break down randomly. The factory requires at least N working machines to operate. When working machines fall below N, the factory halts production.

Goal: Simulate the time until factory first halts production.

Simulation Parameters

Total number of machines in factory
Minimum required working machines (N < M)
Average time to repair a machine
Standard deviation of repair times
Average time between breakdowns
Standard deviation of breakdown times
How many simulation runs to perform

How the Simulation Works

Discrete-Event Simulation Approach:

  • Each machine starts in working state with a random breakdown time
  • When a machine breaks down, it moves to repair queue
  • After repair, machine returns to working state with new breakdown time
  • Simulation stops when working machines < N
  • Output: Time until factory halt and statistics

Default Parameters (from problem):

  • M = 10 total machines
  • N = 6 minimum working machines required
  • Repair Time: Normal(μ=100, σ=50) - positive values only
  • Breakdown Time: Normal(μ=300, σ=80) - positive values only
